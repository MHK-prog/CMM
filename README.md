# CMM — تکمیل و ساخت کارنامه

این وب‌اپ مستقل و آفلاین کنار پروژهٔ Class Manager قرار دارد و به سرور یا کتابخانهٔ بیرونی نیاز ندارد. برای استفاده، فایل index.html را در مرورگر باز کنید.

## مسیر کار

1. در Class Manager از صفحهٔ «خروجی»، گزینهٔ «خروجی نمرات مجاز برای CMM (JSON)» را دانلود کنید.
2. در CMM فایل JSON را وارد کنید. CMM همچنین فایل پشتیبان کامل backup_grades.json را می‌پذیرد.
3. برای هر زبان‌آموز نام، نام پدر، کد ملی و نمرات کارنامه را تکمیل کنید.
4. «دریافت ZIP کارنامه‌ها» را بزنید. ZIP شامل یک HTML مستقل برای هر زبان‌آموز است.

اطلاعات هر دو برنامه در مرورگر همان دستگاه نگهداری می‌شود. نام معلم در خروجی کارنامه درج نمی‌شود.

## نمره‌های قابل‌ویرایش در Class Manager

Class Manager فقط این سه نمرهٔ کارنامه را در اختیار معلم می‌گذارد: فعالیت کلاسی از ۴۰، میان‌ترم از ۴۰ و انضباط از ۱۰. خروجی اختصاصی CMM نیز فقط همین سه مورد را حمل می‌کند. سایر مشخصات و نمره‌ها در برنامهٔ مستقل CMM تکمیل می‌شوند.

قالب HTML کارنامه از نمونهٔ ارائه‌شده الهام گرفته و شامل پنج تم، مشخصات زبان‌آموز، نوار نمره‌ها، جمع از ۲۰۰ و وضعیت قبولی است.
